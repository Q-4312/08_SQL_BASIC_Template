# 1️⃣ 개념 정리

아래 키워드 중 중요하다고 생각한 개념을 2개 이상 골라 짧게 정리해주세요. 3개보다 더 많이 정리하고 싶다면 자유롭게 항목을 추가해도 좋습니다.

이번 주 키워드:
- SELECT
- FROM
- WHERE
- 조건식
- ORDER BY
- LIMIT
- 테이블 구조 확인

## 01.

```
개념 이름: Select
개념 설명: 테이블에서 추출하고픈 컬럼명, AS로 별칭 설정 가능, 쿼리 연산 실행 순서 3순위
예시 쿼리: Col1 AS new_name, *(모든 컬럼 출력), * EXCEPT(제외할 컬럼)
```

## 02.

```
개념 이름: From
개념 설명: 데이터를 확인할 테이블 명시, AS로 별칭 설정 가능 쿼리 연산 실행 순서 1순위
예시 쿼리: Dataset.Table의 형태 (ex. basic.pokemon)
```

## (선택) 03.

```
개념 이름: Where
개념 설명: 원하는 조건을 명시, 필터링, 쿼리 연산 실행 순서 2순위
헷갈린 점: Where이라는 단어에서 오는 직관 때문에 특정 조건보다는 데이터를 가져오는 장소가 공간이라고 계속 은연 중에 생각하게 되었지만, Where를 쓰기에 앞서 쓰는 From과 연결하여 생각하면 의미를 보다 명징히 떠올릴 수 있게 되었습니다.
```
