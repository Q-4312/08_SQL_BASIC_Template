# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 중고 거래 앱
- 떠올린 컬럼 5가지: 구매자정보, 판매자정보, 물품정보, 거래지역, 거래금액
- 해당 컬럼이 필요하다고 생각한 이유: 유저들의 정보, 특히 구매자와 판매자를 구분하여 각각의 유저가 가지는 특징을 추출하는 것이 분석에 있어 중요한 부분이라고 생각했고, 어떤 물품이 어디서 어떤 가격으로 오갔는지를 아는 것은 가장 기본적인 내용이라고 생각했기 때문입니다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 데이터 탐색 및 데이터 결과 검증에 사용되는 가장 기본적인 언어라고 생각했기 때문입니다.
- SQL로 해보고 싶은 일: 매번 파이썬 코딩을 통해서만 데이터 분석을 해왔는데, 앞으로 SQL이라는 새로운 도구를 이용하여 보다 편리하고 조금 더 다방면으로 분석을 진행해보고 싶습니다.
- 앞으로 SQL을 공부할 때 기대되는 점: 아직 많은 것을 알지 못하지만, 잠깐 살펴봤을 때의 SQL은 다양한 결과를 도출해낼 수 있을 것 같아 분석에 있어서 제 시야를 넓히는 좋은 기회가 될 것 같습니다.
```
