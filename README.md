<h1 align="center">SQL BASIC Template</h1>

**SQL BASIC 8기 정규 과제 템플릿**입니다.  
이 레포지토리는 SQL을 처음 학습하는 학회원이 7주 동안 강의 수강, 핵심 개념 정리, SQL 문제 풀이를 진행할 수 있도록 구성되어 있습니다.

---

## 📌 과제 진행 방식

SQL_BASIC 정규 과제는 매주 정해진 분량의 `초보자를 위한 BigQuery(SQL) 입문` 강의를 듣고, 핵심 개념을 짧게 정리한 뒤 프로그래머스 SQL 문제를 직접 풀어보는 방식으로 진행합니다.

각 주차 과제는 아래 항목으로 구성되어 있습니다.

- 강의 수강 계획 확인
- 선택 강의 확인
- 핵심 개념 정리
- 수행 인증
- 확인 문제 풀이
- 주차별 회고

---

## 🗓️ 7주차 커리큘럼

| 주차 | 주요 학습 내용 |
| --- | --- |
| 1주차 | BigQuery 기초, SQL 기본 구조 |
| 2주차 | `SELECT`, `FROM`, `WHERE` |
| 3주차 | 집계 함수, `GROUP BY`, `HAVING` |
| 4주차 | 쿼리 작성 흐름, 타입 변환, 문자열 함수 |
| 5주차 | 날짜/시간 데이터, `CASE WHEN` |
| 6주차 | `JOIN`, `INNER JOIN`, `LEFT JOIN` |
| 7주차 | 전체 개념 복습 |

---

## 📂 폴더 구조

`assignment` 폴더에는 1주차부터 7주차까지의 과제 파일이 들어 있습니다.  
`check.md`에는 각 주차 확인 문제의 링크, 주제, 난이도가 정리되어 있습니다.

---

## ✅ 제출 방법

1. 매주 해당 주차의 과제 파일을 작성합니다.
2. 강의 수강 화면, 문제 풀이 정답 화면 등 수행 인증 자료를 첨부합니다.
3. 작성한 과제를 Github에 업로드합니다.
4. 업로드한 Github 링크를 스프레드시트 `SQL` 시트에 입력해 제출합니다.

---

## ⚠️ 유의사항

- 과제는 Markdown 형식(`.md`)으로 작성합니다.
- 수행 인증란은 필수입니다.
- 프로그래머스 문제는 로그인이 필요하므로 로그인 후 풀이를 진행해주세요.
- 문제를 맞춘 뒤 정답 화면을 캡처해 각 문제 아래에 첨부해주세요.
- 개념 정리는 길게 작성하기보다, 본인이 중요하다고 생각한 개념을 짧고 명확하게 정리해주세요.
